# PLAYTEST 联调指南

## 环境准备

- PC 与手机同一局域网(WiFi)。
- PC 打开游戏 URL(开发: `http://localhost:5173/webrtc/`; 部署: `https://hana-ame.github.io/webrtc/`)。**注意: 真机陀螺仪需要 HTTPS**(本地可用自签名/隧道)。
- 手机浏览器访问同一 URL(可扫 PC 屏幕上的二维码)。

## 桌面自测(无手机)

同一浏览器开两个标签:

1. `#/pc` → 记录房间码。
2. `#/mobile?sim=1` → 手输房间码 → 点「加入」→ 校准 → 进入遥控界面(模拟器会每秒挥舞)。
3. 回 PC 标签点「开始游戏」→ 观察音符被击中/漏击。

## 真机联调步骤

1. **PC**: 进入 → 选「我是 PC 显示器」→ 生成房间, 等待连接。
2. **Mobile**: 选「我是手机控制器」→ 从列表点房间, 或扫码/输码。
3. **校准**: 先选难度(简单/普通/困难)。手机竖直举在身前(屏幕朝向自己、顶边朝上), 点「开始校准」→ 保持静止 3 秒 → 「校准完成」→ 点「进入游戏」。
   - iOS 首次会弹陀螺仪权限请求, 需允许。
   - 握持姿势不对可随时「重新校准」。
4. **开始**: PC 点「开始游戏」。音乐响起, 音符沿 3×3 网格飞向玩家。
5. **击打**: 像挥光剑一样快速转动手机把音符击回。击打时刻 = 音符接近胸前时。有震动反馈。
6. 漏击 3 次结束, PC 显示分数面板。

## 调试建议

| 症状 | 排查 |
|------|------|
| Mobile 列表为空 | MQTT 公共 broker 偶发慢; 直接手输房间码(PeerJS 不依赖 MQTT) |
| 连不上/超时 | PeerJS 公共云不可达, 已自动重试; 换网络重试; 房间码与 peerId 要一致(`beatrift-{code}`) |
| 剑方向反了/左右反 | 陀螺仪轴符号因机型而异, 调 `src/motion/sensor.js` 中 `_onDeviceMotion` 的 `w` 符号 |
| 剑缓慢漂移 | 重力修正只修俯仰/横滚, 偏航会随时间漂移; 重新校准即可 |
| 命中率极低 | 挥击要「快+准」, 窗口约 ±150ms; 先练习挥到位再加快 |
| 判定太严 | 调 `src/game/gameplay.js` 的 `HIT_RADIUS` / `HIT_STEPS` |

## 体感说明(2026-08 新版)

- 姿态 = **DeviceMotion `rotationRate`(陀螺仪)角速度积分**, 消除 alpha/beta/gamma 欧拉角的 ±90°/±180° 边界翻转。
- 低速时用**加速度计重力修正**(水平仪=绝对角度, 手机三轴=设备坐标), 锚定"上"= 真实重力上方向,
  姿态与校准姿势无关、确定性强; 挥舞时自动暂停修正。
- **握拍模型**: 手机屏幕 = 拍面。**剑的方向 = 屏幕朝向(屏幕法线)**。
  - 拍面正对音符 → 剑直指音符
  - 左挥拍 → 剑扫向左侧; 右挥拍 → 右侧
  - 压拍头指高音 → 剑朝上; 收拍头指低音 → 剑朝下
- 手持不看屏幕, 像拿球拍一样挥手机即可。
- 若设备没有 `DeviceMotion`, 自动回退到 `DeviceOrientation`。

## 难度选择(校准屏)

校准界面可选择 简单 / 普通 / 困难, 随 `READY` 发给 PC, 影响:
- 判定半径(`hitRadius`)与节拍窗口(`hitSteps`): 越大越容易中
- 手机挥击触发灵敏度(`swingPeak`/`swingMin`): 越低越容易触发挥击

默认「简单」。数值在 `src/constants.js` 的 `DIFFICULTY` 表里。

## 无敌模式

`src/constants.js` 中 `GAME.INVINCIBLE = true`: 漏击不断命、不结束, 生命显示 ∞, 可无限玩。
游戏结束面板通过 PC 屏幕右上角「退出」按钮调出。

## 性能提示

- PC 渲染: WebGL, 关掉其它重 GPU 标签。
- 手机: 只发陀螺仪数据, 屏幕可熄(AudioContext 保持); 关闭省电模式避免降频。
